# Hack Club Build Guild Hyd 2026 - PCB Design - Rickroll NFC Card
Hey there, I have made this PCB @ [Hack Club Build Guild Hyd 2026](https://akahackclub.xyz) hosted at Aga Khan Academy. During this event we learnt how to make a PCB and how to build a drone.
The gerber files for this PCB are kept at /Gerber_files and the .epro(easyeda file) file has also been uploaded. BOM_PCB.xlsx is the Bill of Materials.
